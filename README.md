# PlayCARD · 客湖战略赌注台 (KEHU Strategy Bet Board)

逼迫诚实的战略工作台。v2 的核心立场：**v1 让人看得清楚，v2 让人不好意思自欺。**

设计依据见《PlayCARD_开发指引_v2.md》，视觉与交互基准为 `playcard-prototype-v2.html` 小样。

## 它服务三件事

1. 把目标改写成**赌注**——强制写出代价（`sacrifice`）与停损条件（`killCondition`）
2. 用**必须为真**的分解（不确定性 × 致命性矩阵），把季度精力压到最不确定且最致命的一两条上
3. 用**资源实际投向**对照声称配比，验证战略是否真的存在

成功判定只有一条：**连续两个季度，资源投向表出现了朝战略方向的实际倾斜。**

## 功能

- **赌注台**：三张引擎赌注卡 + 红灯样本；卡片正面显示编号、引擎、可逆性、体检四项 chip（未通过亮红）、判据读数与先行/滞后标记、停损倒计时、30 天动作剩余天数。不可逆赌注置顶标识。
- **必须为真矩阵**：横轴不确定性、纵轴致命性；右上象限金色标注「本季度唯一该验证的」，自动汇总成一句验证焦点。点击赌注卡切换。
- **资源投向对照**：声称配比 vs 实际人天占比，差值 ≥10 个百分点标红；底部固定判定语。
- **详情抽屉**：赌注五要素 / 必须为真列表 / 空头意见与证伪信号（与正方并列、不折叠）/ 判据 / 复盘时间线。
- **赌注录入与编辑**（桌面端）：保存受**体检硬拦截**——`sacrifice`、`killCondition`、30 天内 `probe`、先行指标四项不满足一律拒绝保存，并给出指引原文提示。移动端只读。
- **持久化**：数据存本机浏览器 `localStorage`（`playcard.v2.*`），可一键重置为种子数据。

## 体检规则（硬拦截）

| 检查 | 通过条件 | 不通过提示 |
| --- | --- | --- |
| 放弃 | `sacrifice` 非空且含具体对象 | 没写放弃什么。这是愿望，不是战略。 |
| 可观测停损 | `killCondition` 含可观测指标与日期 | 停损条件无法观测。半年后没人能判定它是否触发。 |
| 30 天动作 | `probe` 非空且 30 天内有截止日 | 没有 30 天内的对外动作。这个判断还没想清楚。 |
| 先行指标 | 判据指标标记为先行 | 判据是滞后指标。等它出结果时纠错已经来不及。 |

## 目录结构

```
index.html        页面骨架（顶栏 / 三年方向 / 统计条 / 赌注台 / 面板 / 抽屉 / 编辑器 modal）
css/style.css     设计系统与全部样式（金色只属于本季验证焦点）
js/data.js        种子数据、引擎映射、日期工具、体检规则、HTML 转义
js/app.js         渲染层：赌注台、矩阵、资源投向、抽屉、状态与持久化
js/editor.js      编辑器：赌注录入/编辑（硬拦截）、配比编辑、方向陈述编辑
```

## 本地运行

纯静态、零依赖，任意静态服务器即可：

```bash
cd "KEHU Company Strategy"
python3 -m http.server 8000    # 或任意静态服务器
# 打开 http://localhost:8000
```

## 部署

静态站点可直接部署到 GitHub Pages / 任意静态托管。

## 种子数据说明

- B-01 数据成功（不可逆）、B-02 客户成功（不可逆）、B-03 技术成功（可逆）为格式示范，文案由战略 owner 逐条确认。
- B-04 是**红灯样本**：体检四项全挂，用于演示系统如何打回不合格赌注；真实环境此类赌注无法被保存。
